# Поддержка (GitHub Pages)

Здесь лежит статическая страница для **Support URL** в App Store Connect и для пользователей без входа в приложение.

## Включение GitHub Pages

1. Репозиторий **lp-web** на GitHub → **Settings** → **Pages**.
2. **Build and deployment** → **Source**: *Deploy from a branch*.
3. **Branch**: `main` (или ваша основная ветка), папка **`/docs`**.
4. Сохраните. Через 1–2 минуты сайт будет доступен по адресу вида:

   `https://<ваш-орг-или-ник>.github.io/lp-web/`

5. Этот URL укажите в App Store Connect в поле **Support URL** (и при необходимости продублируйте ссылку в описании приложения).

Контакты на странице (`index.html`) должны совпадать с реальными каналами поддержки. При смене телефона или Telegram обновите файл и дождитесь обновления Pages.

## Локальная проверка

Откройте `docs/index.html` в браузере (двойной клик или через локальный сервер).
